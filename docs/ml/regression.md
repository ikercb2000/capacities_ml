# Choquet regression

`ChoquetRegressor` fits a normalized monotone capacity by least squares and adds a separate intercept.

## Model

For an observation $x\in\mathbb R^n$, the fitted model is

\[
\widehat y
=
\beta_0 + C_\mu(x),
\]

where $C_\mu$ is the discrete Choquet integral and $\mu$ is learned subject to the constraints generated by the chosen `CapacitySparsity` specification.

The default sparsity is `FullCapacity()`. In most empirical applications with more than a few features, a low-order Möbius representation such as `KAdditivity(order=2)` is easier to estimate and interpret.

## Basic usage

```python
from capacities_ml_fin.ml.models import ChoquetRegressor
from capacities_ml_fin.ml.optimization import KAdditivity

regressor = ChoquetRegressor(
    sparsity=KAdditivity(order=2),
    solver="scipy",
)
regressor.fit(X_train, y_train)

y_pred = regressor.predict(X_test)
```

After fitting, important attributes include:

- `capacity_` — decoded learned capacity;
- `intercept_` — fitted additive intercept;
- `problem_` — solver-independent optimization specification;
- `result_` — backend-independent optimization result;
- `sparsity_` — the effective capacity parameterization;
- `universe_` — fitted feature universe;
- `solver_` — resolved `Solver` enum.

## Why normalize the predictors?

A capacity is monotone in its criteria. If one feature is a benefit and another is a cost, raw values do not share a common semantic direction. The package therefore provides `CapacityNormalizer`.

```python
from sklearn.pipeline import Pipeline
from capacities_ml_fin.ml.preprocessing import CapacityNormalizer

pipeline = Pipeline(
    [
        (
            "normalize",
            CapacityNormalizer(cost_features=["volatility"]),
        ),
        (
            "model",
            ChoquetRegressor(sparsity=KAdditivity(order=2)),
        ),
    ]
).set_output(transform="pandas")
```

A cost feature is scaled and then reversed so that a larger transformed value represents a more desirable outcome, matching the orientation of benefit criteria.

## Objective and parameterization

For training observations $(x_t,y_t)$, the core objective is

\[
\min_{\mu,\beta_0}
\sum_t
\left[y_t-\beta_0-C_\mu(x_t)\right]^2
+
\operatorname{penalty}(\theta),
\]

where $\theta$ denotes the optimized parameter vector and the penalty is optional.

The implementation exploits that the Choquet integral is linear in either the explicit capacity values or the selected Möbius coefficients once the observation matrix is fixed. A design matrix is built before optimization.

## Interaction order selection

The repository regression notebook treats $k$ as a hyperparameter:

```python
from sklearn.model_selection import GridSearchCV, KFold
from capacities_ml_fin.ml.model_selection import capacity_parameter_grid

search = GridSearchCV(
    pipeline,
    capacity_parameter_grid(
        parameter_name="model__sparsity",
        orders=(1, 2, 3),
    ),
    scoring="neg_mean_squared_error",
    cv=KFold(n_splits=3, shuffle=True, random_state=4),
)
search.fit(X_train, y_train)
```

For ordered time-series data, replace shuffled CV with an appropriate temporal splitter.

## Regularizing selected parameters

`L1Penalty` and `L2Penalty` apply only to positions selected in the global optimization vector. For a $k$-additive representation, one useful pattern is to penalize interaction terms but leave singleton terms unpenalized.

```python
import numpy as np
from capacities_ml_fin.ml.optimization import L1Penalty

compilation = best_sparsity.compile(X_train.shape[1])
interaction_positions = np.array(
    [
        pos
        for pos, mask in enumerate(compilation.bundle.parameter_masks)
        if mask.bit_count() >= 2
    ],
    dtype=int,
)

penalty = L1Penalty(
    weight=5e-4,
    selection=interaction_positions,
)

model = ChoquetRegressor(
    sparsity=best_sparsity,
    penalty=penalty,
)
```

This encourages a simpler interaction structure without shrinking the entire model indiscriminately.

## Interpret the learned capacity

```python
from capacities_ml_fin.base.interpretation import (
    shapley_indices,
    pairwise_interactions,
    pairwise_interaction_matrix,
)

importance = shapley_indices(regressor.capacity_)
interactions = pairwise_interactions(regressor.capacity_)
matrix = pairwise_interaction_matrix(regressor.capacity_)
```

The Shapley indices summarize global variable importance in the capacity. Pairwise interactions summarize complementarity or redundancy of the aggregation rule.

## Compare with an additive baseline

`KAdditivity(order=1)` is a natural capacity-based additive baseline. A standard `LinearRegression` remains useful as a conventional benchmark, especially because the Choquet regressor has a structured monotone aggregation rather than arbitrary signed linear coefficients.

```python
from sklearn.linear_model import LinearRegression

linear = Pipeline(
    [
        ("normalize", CapacityNormalizer(cost_features=["volatility"])),
        ("model", LinearRegression()),
    ]
).set_output(transform="pandas")
```

Compare both on held-out data using the same preprocessing and split.

## Solver choices

`ChoquetRegressor` accepts strings or `Solver` values. The default is SciPy. CVXPY is available for objective/constraint combinations with a symbolic translation; PYMOO can be used when a derivative-free evolutionary search is desired.

For ordinary least-squares capacity learning, SciPy is the simplest default in the current implementation.

## Important limitations

- Full capacities scale exponentially with the number of features.
- Exact Shapley and interaction interpretation also scales combinatorially.
- Monotonicity encodes a structural assumption: after orientation, increasing a criterion should not reduce the Choquet aggregate.
- An intercept is estimated separately and is not part of the capacity.
